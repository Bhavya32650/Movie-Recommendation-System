# 🎬 Week 6 — Movie Recommendation System: Backend, Frontend & Deployment

## 📌 Project Overview

The Movie Recommendation System is a machine learning-based application that helps users discover movies through similarity-based recommendations, personalized suggestions, and popular movie selections.

**Week 6 Focus:** Extending the Week 5 machine learning project into a complete web application by integrating backend APIs, database management, frontend development, testing, security, and cloud deployment.

## 🎯 Objectives

- Reuse the trained Week 5 Movie Recommendation Model.
- Develop an interactive frontend using Streamlit.
- Allow users to explore and search for movies.
- Generate similar movie recommendations.
- Provide personalized movie recommendations.
- Display popular movies and recommendation analytics.
- Deploy the application and make it accessible through a public URL.

## ✅ Tasks Completed

### 1. Machine Learning Model Integration
- Reused the Week 5 trained Movie Recommendation Model.
- Integrated the recommendation logic into the application.
- Implemented movie similarity and personalized recommendation functionality.
- Included popular movie recommendations as a fallback.

### 2. Frontend Development
- Developed the frontend using Streamlit.
- Created a clean and user-friendly interface.
- Designed a light theme with lavender, purple, and teal accents.
- Added the following sections:
  - Explore Similar Movies
  - Personalized Recommendations
  - Popular Movies
  - Analytics Dashboard

### 3. Application Deployment
- Maintained the project in GitHub.
- Used Streamlit Community Cloud for application deployment.
- Connected the GitHub repository to Streamlit Community Cloud.
- Configured the application entry point as `app/streamlit_app.py`.
